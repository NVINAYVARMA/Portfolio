# V2-Portfolio — Vinay Varma

> High-performance modern SaaS & creative engineering portfolio built with React 19, Vite, Three.js, WebGL shaders, and Rapier physics.

🌐 **Live URL**: [https://v2-portfolio-33om.onrender.com](https://v2-portfolio-33om.onrender.com)

---

## ✦ Core Features

- **3D Interactive Rubik's Kinetic Loader**: Fast, fluid monochrome titanium solve animation with instant `[Esc]` skip.
- **Half-Body Morphing Portrait**: Interactive WebGL fragment shader morphing portrait between natural and wave gestures with precise upper-body framing.
- **Interactive 3D ID Badge**: Physics-driven 3D lanyard with dynamic cloth joint constraints powered by `@react-three/rapier` (BVRIT student credential).
- **3D DriftWall & Polaroid Strip**: High-performance pseudo-random drift wall showcasing authentic hackathon milestones, trophies, and awards at BVRIT with click-to-lightbox inspection.
- **Interactive Physics Stack**: Real-time Matter.js rigid-body physics collision simulation featuring core engineering competencies.
- **Ambient WebGL Flow**: Smooth background fluid shader and cosmic particle systems rendering 60fps ambient textures.
- **Unified Navigation & SPA Routing**: Monochromatic floating pill navigation system with zero-lag routing.

---

## ✦ Tech Stack

- **Frontend**: React 19, Vite 8, React Router 7, Framer Motion
- **3D Graphics & Physics**: Three.js, @react-three/fiber, @react-three/drei, @react-three/rapier, Matter.js, OGL
- **Styling**: Monochromatic CSS design system with GPU-accelerated transitions
- **Deployment**: Render Static Site / Vercel Edge with client rewrite rules

## ✦ Local Development

```bash
# Clone the repository
git clone https://github.com/NVINAYVARMA/Portfolio.git

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
